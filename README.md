# noodles
a website made for the hackclub noodles ysws

## Overview 
ok so i made a fun, interactive and helpful website (hopefully) to provide instuctions and easy to follow step by step directions for peasy making at home :p this little messy craetion of mine has a receipe and detailed outline of various steps, it even includes an ingredient list. Aditionally i've included some basic horizontal scrolling experince as well as images with each step from 0 till 8. Furthermore it also includes a cute pizza heart in step 0 (just for that touch of cuteness and whimsy)


index.html has the overall page structure and contains the receipe slide, it also has the intro slide called step 0. Furthermore that intro style also contains a heart image for this pizza receipe website 

index.js is the file that contians and controls the basic level animations. i have also made use of Gsap and scrolltrigger which enables horizontal page scrolling. There is also a progress bar update which shows how far you/the user has horizontally scrolled.

style.css this file loads the tailwind and has any custom/extra css, those custom styles include e.g, the heart imggea sizing or some layout changes.

package.json contains the dependencies such as Gsap and tailwind cssas well as scripts.
